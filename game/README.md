# 🧠 Neuron Cognitive Memory Gym

A specialized, multi-sensory cognitive sharpening game designed for patients with **Alzheimer's Disease, Dementia, and Mild Cognitive Impairment (MCI)**.

---

## 🎯 Therapeutic Objectives & Scientific Rationale

1. **Anxiety-Free Positive Reinforcement**:
   - Traditional games often include rapid count-down timers and punitive "Game Over" screens that trigger agitation and anxiety in dementia patients.
   - The Neuron Memory Gym features **calm pacing**, **gentle retry sounds**, and an unrestricted **"Peek at Cards"** hint assistant.

2. **Multi-Sensory Neural Stimulation**:
   - Uses synthesized auditory chimes (Web Audio API) mapped to specific pitches, activating auditory and visual pathways simultaneously.
   - Familiar, high-contrast visual anchors (Eyeglasses, Keys, Medicine, Photo Album, Clock, Teacup) reinforce everyday memory.

3. **Multi-Domain Cognitive Exercise**:
   - **Cortex Match**: Visual-spatial short-term memory & recognition.
   - **Neuro-Sequence**: Working memory, temporal sequence recall, and rhythm.
   - **Daily Life Recall**: Autobiographical & semantic memory associated with daily living routines.

## 🚀 How to Run

### Option 1: Inside Neuron Main Web UI
Launch the Neuron frontend (`cd frontend && npm run dev`), then:
- Click **`MEMORY GYM`** in the top navigation bar.
- Or click **`PLAY MEMORY GAME`** on the Landing Page.
- Or select **`Play Memory Game`** in the Patient Cortex suggestions.
